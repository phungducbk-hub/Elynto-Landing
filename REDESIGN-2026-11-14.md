# Still Harbor landing redesign — 14 November 2026

## Source of truth and authorization
The user explicitly authorized access to beta.elynto.io for read-only UI inspection, with sample data only in the landing demo and no changes to application data. The existing browser session was already authenticated. No sign-in credentials were requested, no command was submitted, and no app records were created or edited.

Reviewed live: Today, My Work, Delegated, Projects, project detail, Ask Elynto drawer, and Plan a project with AI. The beta’s Today at a glance is explicitly labelled SAMPLE DATA, so it must not be described as a live intelligent briefing.

## Implemented
- Still Harbor #1a6289, Inter, canvas #f7f7f8, text #1a2530 and border #dbe0e6 across Vietnamese/English and feature pages.
- A wider product-led hero and a navigable Today / My Work / Delegated demo with mouse and keyboard controls.
- Shared beta app shell: white sidebar, actual navigation labels including Chat and Meetings, compact header, Ask Elynto and bottom composer.
- Work previews use the real Upcoming / Overdue / Rework or Approval / Completed / Archived structure and table columns. Every name, task and workspace in the demo is fictional.
- The command visual now matches the observed Ask Elynto drawer. Removed the invented green success-card animation; submitting a command would change app data, so its generated-result layout was not inspected or claimed to be verified.
- The planner preview matches the observed goal-entry form, rather than inventing a generated-plan layout. Removed the unverified 10-second claim.
- Project preview uses the shared shell, six overview fields, health and milestones. Its List / Calendar / Gantt previews retain the prior sample dataset; Calendar/Gantt content remains illustrative, based on the earlier supplied beta references rather than a fresh live check in this session.
- Kept product UI text in English, matching the observed app, within both marketing languages.
- Removed the long animated situations wall from the home page to shorten the product story. No fabricated testimonials or customer metrics added.
- Updated feature-page daily-work copy so Today’s sample briefing is not described as production reporting.
